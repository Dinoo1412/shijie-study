# 第 1 周 · Python 起步

目标：运行计算器和猜数字游戏

## Day 1 · 环境搭建与第一个程序

打开 exercises/week01/day01.py。先在终端运行 python --version，再运行 python exercises/week01/day01.py。修改问候语，询问年龄并输出十年后的年龄。

- [ ] 能在终端看到 Python 版本
- [ ] 能运行并修改 .py 文件
- [ ] 能解释 print、input 与 f-string

## Day 2 · 变量、数字与字符串

创建个人信息程序，保存姓名、年龄、城市、学习目标；使用 f-string 输出一段介绍，修改变量后再次运行。

- [ ] 使用至少四个有含义的变量
- [ ] 能区分数字 23 与字符串 "23"
- [ ] 能用 type 检查类型

## Day 3 · 类型转换与四则运算

写一个四则运算计算器。先处理正常输入；列出空输入、非数字、除以零三种失败情况，下一天增加除零分支。

- [ ] 正确计算整数与小数
- [ ] 能说明 int 和 float 的区别
- [ ] 记录至少三种异常输入

## Day 4 · 条件判断

实现成绩等级判断：90–100 优秀、80–89 良好、60–79 及格，其余不及格。补充计算器的除零保护。

- [ ] 正确判断 59、60、79、80、89、90
- [ ] 拒绝小于 0 或大于 100 的分数
- [ ] 分支缩进一致

## Day 5 · for、while 与循环

输出九九乘法表；再用 while 写从 1 累加到 100 的程序。尝试故意忘记更新计数器，理解死循环后按 Ctrl+C 停止。

- [ ] 乘法表输出九行
- [ ] 1 到 100 的和为 5050
- [ ] 能解释 range(1, 10) 的范围

## Day 6 · 猜数字游戏

实现猜数字游戏，加入尝试次数计数和范围检查。最多猜 7 次；失败时显示答案。

- [ ] 能提示太大或太小
- [ ] 猜中后结束循环
- [ ] 限制最多七次有效尝试

## Day 7 · 第一周复习与验收

不看示例重写计算器和猜数字游戏。给每个程序设计五组输入，把预期输出与实际输出记在笔记中。

- [ ] 独立完成两个程序
- [ ] 至少测试五组输入
- [ ] 用自己的话解释每个分支与循环
