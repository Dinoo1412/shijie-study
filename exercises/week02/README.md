- [ ] 去重后没有重复项

- [ ] 能增删改查键值

- [ ] 处理连续逗号与空格

- [ ] 函数可多次调用

## Day 13 · 推导式与排序

- [ ] 成绩按降序排列

开发命令行学生管理程序，支持新增、按姓名查询、更新成绩、删除和排名。用菜单循环处理命令。

- [ ] 五种操作都可运行
- [ ] 拒绝重复姓名与非法分数
