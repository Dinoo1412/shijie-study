# 第 4 周 · 进阶入门

目标：完成可处理失败的天气查询程序

## Day 22 · 迭代器与生成器

写一个逐行读取文本的生成器；统计非空行数量，解释它与一次性 read 的区别。

- [ ] 使用 yield 返回多个值
- [ ] 能按顺序消费生成器
- [ ] 知道生成器耗尽后不能直接重用

## Day 23 · 装饰器入门

写一个记录函数耗时的装饰器，使用 time.perf_counter。确认装饰后保留原函数返回值。

- [ ] 装饰器接收并返回函数
- [ ] 参数正确传递
- [ ] 原始返回值不丢失

## Day 24 · 类型注解与代码组织

- [ ] 关键参数与返回值有注解
- [ ] 函数职责清楚

## Day 25 · HTTP API 请求

实现固定城市坐标的天气查询。检查响应字段并处理超时、网络失败和缺失字段；保留一个本地 JSON 样例用于离线测试。

- [ ] 解析并输出温度与单位
- [ ] 请求设置超时
- [ ] 网络不可用时输出明确提示

## Day 26 · async 与 await 入门

对比顺序等待两个任务与 gather 并发等待的耗时。解释为什么异步不会让纯计算自动变快。

- [ ] 能运行异步入口
- [ ] 测量两种执行方式耗时
- [ ] 能解释等待时协程切换

## Day 27 · Git 基础与版本记录

为自己的练习创建本地 Git 仓库。修改一处代码，查看 diff 并提交。确认 .venv、缓存和密钥文件不在提交中。

- [ ] 能查看工作区和暂存区状态
- [ ] 能完成本地提交并查看历史
- [ ] 能解释未跟踪与已修改文件
