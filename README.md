# 拾阶 · AI 工程师学习工作台

面向零基础学习者的在线学习工作台，以 52 周课程串联 Python、后端开发、LLM、RAG 与 Agent 实践。打开网站即可学习，无需启动本地服务。

## 在线使用

在线网站：[打开拾阶](https://shijie-study.jean1412.workers.dev)。电脑与手机浏览器均可使用。

1. 点击“继续学习”，阅读课程并完成验收清单。
2. 在课程中下载练习文件或打开每周任务说明。Python 练习需在自己的开发环境运行。
3. 记录笔记，使用专注计时，定期导出备份。

在“学习设置与备份”中使用 GitHub 登录，同一账号的课程进度、笔记、项目验收、时间记录及学习设置会保存到云端，在其他浏览器或设备登录后恢复。切换设备前请确认显示“已同步到云端”；在线页面约每 15 秒获取更新。

未登录时，记录保存在当前浏览器。首次登录不会自动覆盖云端记录；如需保留以前的学习进度，请在原浏览器登录，先导出备份，再使用“迁移”按钮。离线修改会保留在本机并在恢复连接后重试；多设备同时修改发生冲突时，需要选择保留哪份记录。专注计时仅在启动它的浏览器运行，结束后产生的时间记录可同步。

## 功能

- 7 个阶段、52 周、364 个学习日。
- 前 28 天详细入门课，后续按周提供实践指引及官方资料入口。
- 课程筛选、验收清单、笔记、计时与学习时长记录。
- JSON 备份导入导出与 Markdown 笔记导出。
- 4 个阶段项目需求及验收清单。
- GitHub 登录、账号数据隔离与跨设备同步。
- 独立 LeetCode 算法专题：8 个阶段、48 道起步题、Python / C++ 分语言进度、复盘与复习队列。
- 8 个 C++ 算法入门准备模块；原有 52 周 AI 学习内容保留。

## LeetCode 算法专题

从导航打开“算法练习”。训练顺序参考[灵茶山艾府的科学刷题分享](https://leetcode.cn/discuss/post/3141566/ru-he-ke-xue-shua-ti-by-endlesscheng-q3yd/)，从编程入门到滑动窗口、二分、数据结构、二叉树递归、网格图、回溯和动态规划。精选起步题和语言准备由拾阶编排；每个阶段都有完整题单入口，48 题并不代表算法训练全部完成。

选择 Python 3 或 C++ 后，在力扣打开题目并提交，回到拾阶手动确认练习结果。两种语言分别保存进度和复盘，登录后随账号同步，也包含在完整 JSON 备份中。算法复盘可另导出 Markdown。

首次 AC 后建议次日复习，独立复做后逐步延长为 3、7、14、30 天。这是拾阶的复习建议。C++ 准备页提供类型、容器、引用、排序、递归与 DP 的练习，不替代完整 C++ 工程课程。原来的课程完成数和时间记录独立保留。

## 网站部署

使用 Cloudflare Workers 托管公开网站，GitHub 源码仓库保持私有。构建生成的 `dist/` 只包含网页及练习文件，开发文档和私人来源信息不会发布。

账号接口由 Worker 提供，进度存储在 Cloudflare D1。GitHub Client Secret 仅作为 Cloudflare 密钥配置，不写入代码或网页。初次部署或迁移环境请参阅[账号部署说明](docs/accounts.md)。

当前网站已通过官方 Wrangler 工具发布。更新网站时运行 `npm run deploy`，需要已登录 Cloudflare。当前尚未绑定 Git 自动部署。若需推送后自动发布，可在 Cloudflare 的 Workers & Pages 中连接私有仓库 `Dinoo1412/shijie-study`：

| 设置 | 值 |
|---|---|
| 生产分支 | `main` |
| 根目录 | 仓库根目录，留空 |
| 构建命令 | `npm run build` |
| 部署命令 | `npx wrangler deploy` |
| 静态资源目录 | `dist`，已在 wrangler.toml 配置 |

首次创建后，Cloudflare 提供公共 HTTPS 地址。连接成功后，推送 main 会自动构建部署。无需配置 GitHub Token 或模型 API Key。

也可在已登录 Cloudflare 的环境中运行 `npm run deploy` 手动发布。

原有 `server.py` 和 `启动学习.bat` 可用于开发预览，网站访客不需要使用它们。
