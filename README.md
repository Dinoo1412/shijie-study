# 拾阶 · AI 工程师学习工作台

根据你分享的聊天中**后来调整的零基础 9–12 个月路线**制作，项目就在 `C:\Users\19139\Desktop\Study`。

## 开始使用

双击 **启动学习.bat**。浏览器会打开 `http://127.0.0.1:8765`。保留启动窗口，关闭它或按 Ctrl+C 后服务停止。电脑已有 Python 3.10，可以运行这个工作台，无需安装额外依赖。

也可以直接双击 **index.html**，页面不依赖网络或第三方库。外部学习资料、天气 API 和后续模型调用需要联网。

**建议长期使用同一个浏览器和同一个打开方式。** `file://` 与本地网页地址使用不同存储；迁移时在设置中导出完整备份，然后在新地址导入。

## 学习方法

1. 在“学习工作台”点击“继续学习”，从第一项未完成课程开始。
2. 阅读概念和示例，到 `exercises/week01/day01.py` 等文件中完成练习。
3. 在电脑终端运行 Python，例如 `python exercises/week01/day01.py`。页面不执行 Python 代码。
4. 真正验证每个验收条件后再勾选，勾选全部项目才能标记完成。
5. 用自己的话写课程笔记，记录代码、实际结果、错误和解决过程。
6. 用专注计时或手动记录分钟数。完成课程不会自动增加时长，避免虚构投入。
7. 每周在练习目录的 README 中写复盘；达到阶段门槛后再进入下个阶段。

## 内容和功能

- 7 个阶段，52 周，364 个学习日；涵盖 Python、网络、Git、后端、LLM、RAG、Agent、MCP、Go 和面试。
- 前 28 天有概念讲解、示例、实操、常见错误、验收与自测。第 5 周起提供按周细分的实践指引，搭配资料使用，不宣称是一套完整讲授教材。
- 每日课程可按阶段、周、完成状态和关键词筛选。
- 课程完成、项目验收和笔记自动保存在当前浏览器。
- 专注倒计时关闭面板后仍运行；刷新后可恢复。达到目标只记录目标时长，提前结束按完整分钟记录。
- 完整 JSON 备份导出、校验后导入；笔记可单独导出 Markdown。
- 4 个阶段项目的需求说明和验收清单。这些是学习时待完成的业务项目，工作台不会把它们标成已实现。

## 计划与数据

设置中的每周学习天数按“每学习日一课”估算完成日期；增加休息日会顺延原来的全周路线。学习时长是建议，不是达到岗位要求的保证。

时间记录按北京时间计日。专注跨午夜时记录在开始日期。连续学习按完成课程或记录时间计算。

数据存于浏览器的 localStorage，**没有云同步或数据库**。清理浏览器数据、使用无痕窗口、换浏览器或改变访问地址可能使记录不可用。请每周导出完整备份。浏览器禁止存储或空间不足时，页面会提示保存失败，此时立即导出备份。

导入将替换当前记录，会提示确认；建议先导出当前备份。导入格式异常时不会替换现有记录。原记录无法解析时，应用暂停覆盖保存，可导出原始记录或导入有效备份。
