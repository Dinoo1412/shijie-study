# 拾阶 · AI 工程师学习工作台

面向零基础学习者的在线学习工作台，以 52 周课程串联 Python、后端开发、LLM、RAG 与 Agent 实践。打开网站即可学习，无需启动本地服务。

## 在线使用

网站部署后可通过公共 HTTPS 地址访问，电脑与手机浏览器均可使用。

1. 点击“继续学习”，阅读课程并完成验收清单。
2. 在课程中下载练习文件或打开每周任务说明。Python 练习需在自己的开发环境运行。
3. 记录笔记，使用专注计时，定期导出备份。

进度、笔记及设置保存在当前浏览器，各访客的数据独立。网站没有账号系统或云同步。换浏览器、设备或访问地址前，请导出完整备份并在新地址导入。

## 功能

- 7 个阶段、52 周、364 个学习日。
- 前 28 天详细入门课，后续按周提供实践指引及官方资料入口。
- 课程筛选、验收清单、笔记、计时与学习时长记录。
- JSON 备份导入导出与 Markdown 笔记导出。
- 4 个阶段项目需求及验收清单。

## 网站部署

使用 Cloudflare Workers 托管公开网站，GitHub 源码仓库保持私有。构建生成的 `dist/` 只包含网页及练习文件，开发文档和私人来源信息不会发布。

在 Cloudflare 的 Workers & Pages 中创建应用并连接私有仓库 `Dinoo1412/shijie-study`：

| 设置 | 值 |
|---|---|
| 生产分支 | `main` |
| 根目录 | 仓库根目录，留空 |
| 构建命令 | `npm run build` |
| 部署命令 | `npx wrangler deploy` |
| 静态资源目录 | `dist`，已在 wrangler.toml 配置 |

首次创建后，Cloudflare 提供公共 HTTPS 地址。连接成功后，推送 main 会自动构建部署。无需配置 GitHub Token 或模型 API Key。

也可在已登录 Cloudflare 的环境中运行 `npm run deploy` 手动发布。

原有 `server.py` 和 `启动学习.bat` 可用于开发预览，网站访客不需要使用它们。

## 验证

`node tests/verify.cjs` 检查课程结构及备份校验；`node tools/build-site.cjs` 生成并检查公开发布内容。
