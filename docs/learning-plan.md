# AI 工程师学习路线

面向零基础学习者的 52 周实践计划。建议每个学习日完成一个任务，按掌握程度调整节奏。

## 阶段

1. Python 基础：语法、数据结构、异常、文件与模块。
2. 工程基础：HTTP、Git、异步与测试。
3. 后端开发：FastAPI、数据库、缓存、认证与部署。
4. 大模型应用：模型 API、提示词、多轮对话与流式响应。
5. RAG：文档处理、向量检索、评估与知识库应用。
6. Agent：工具调用、状态图、MCP、持久化与恢复。
7. 工程交付：Go、可观测性、项目整合与面试准备。

每日内容、阶段目标及资料入口见网站课程；练习任务见 exercises 各周目录。四个阶段项目为任务管理、AI 聊天、RAG 知识库和 Agent 办公助手。

以实际运行结果和验收条件判断完成度；保存每周复盘和可复现的项目说明。
