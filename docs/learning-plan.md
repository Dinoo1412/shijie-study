## 三、第 1 个月：从零学习 Python

这个月不要着急接触 LangChain、Dify 或 RAG。先把 Python 编程基础建立起来。

### 第 1 周：认识编程环境和 Python

**学习目标：能够自己创建 Python 项目、运行代码、理解最简单的程序。**

| 天数 | 学习内容 | 具体练习 |
|--------|--------|--------|
| Day 1 | 安装 Python、VS Code、认识终端 | 运行第一个 `hello.py` |
| Day 2 | 变量、数字、字符串 | 编写个人信息输出程序 |
| Day 3 | `int`、`float`、`str`、`bool` | 编写简易计算器 |
| Day 4 | `if`、`elif`、`else` | 编写成绩等级判断程序 |
| Day 5 | `for`、`while` | 输出九九乘法表 |
| Day 6 | 综合练习 | 编写猜数字游戏 |
| Day 7 | 复习 | 不看教程重写前六天的程序 |

第一天可以直接按以下步骤操作。

1. 从 [Python 官网](https://www.python.org/downloads/)安装 Python 3。
2. 安装 [VS Code](https://code.visualstudio.com/)。
3. 创建文件夹 `python-learning`。
4. 在 VS Code 中打开这个文件夹。
5. 创建 `hello.py`，输入下面的代码。

```python

name = input("请输入你的名字：")
age = int(input("请输入你的年龄："))

print(f"你好，{name}！")
print(f"明年你就 {age + 1} 岁了。")
```

打开终端，运行：

```bash
python hello.py
```

你需要理解 `input()` 为什么返回字符串、`int()` 为什么可以转换数据类型、`print()` 为什么能输出内容，以及 `f-string` 的作用。

不要只复制代码。尝试修改程序，让它能够计算你十年后的年龄。

这周要特别重视字典。

因为以后调用 LLM API、处理 Agent 状态、传递工具参数时，你会经常接触 JSON 和 Python 字典。

### 第 3 周：Python 工程基础

学习模块导入、包管理、虚拟环境、异常处理、文件读写、JSON、面向对象编程。

每天都要练习：

- `try / except` 捕获错误

周末项目：编写一个命令行待办事项管理器，能够添加、查询、完成和删除任务，并将数据保存到 JSON 文件。

### 第 4 周：Python 进阶入门

学习：

最后完成一个“天气查询程序”，使用公开天气 API 获取数据、解析 JSON、处理请求失败并输出结果。

这个月的验收标准：**不依赖 AI 直接生成完整程序，你能独立编写一个 200 行左右的小型 Python 项目，并能解释主要代码。**

## 四、第 2 个月：计算机基础与 Python 进阶

这一阶段的重点是理解程序如何运行，以及不同系统之间如何通信。

### 第 5 周：计算机网络

按顺序学习：

1. IP 地址是什么？
2. 端口是什么？
3. DNS 如何解析域名？
4. TCP 与 UDP 有什么区别？
5. HTTP 请求和响应是什么？
6. GET、POST、PUT、DELETE 有什么区别？
7. HTTPS 为什么更安全？

练习：使用 Postman 或 Apifox 请求公开 API，查看请求头、状态码、响应体，并用 Python 重现请求。

### 第 6 周：Linux 与 Git

学习 Linux 文件目录、权限、进程、端口、环境变量，以及常用命令。

重点掌握：

```bash
pwd
ls -la
cd
mkdir
cat
grep
ps aux
ss -lntp
chmod
curl
```

Git 重点掌握 `init`、`add`、`commit`、`branch`、`merge`、`pull`、`push`。

练习：在本地创建 Git 仓库，提交 Python 项目，再推送到 GitHub。

### 第 7 周：数据结构与算法入门

先学习时间复杂度、数组、链表、栈、队列、哈希表、二分查找和排序算法。

不必立刻刷大量困难题。每天用 Python 独立完成 1–2 道基础题，重点理解解题思路。

### 第 8 周：异步编程基础

理解：

- 同步与异步
- 阻塞与非阻塞
- 线程与进程
- 协程
- 事件循环
- `asyncio.gather()`

练习：同时请求 10 个 API，对比同步请求和异步请求的执行时间。

第二个月验收标准：能够解释一次 HTTP 请求的基本流程，能使用 Git 管理项目，并能独立编写简单的异步 Python 程序。

## 六、第 5 个月：大语言模型基础

从这里正式进入 AI 应用开发。

### 需要理解的核心概念

| 概念 | 零基础理解 | 为什么重要 |
|--------|--------|--------|
| LLM | 能够理解和生成文本的大模型 | Agent 的核心推理组件 |
| Token | 模型处理文本的基本单位 | 影响上下文与成本 |
| Prompt | 向模型提供的指令与上下文 | 影响输出效果 |
| Context Window | 模型一次能够处理的上下文范围 | 决定输入容量 |
| Embedding | 将文本映射为向量 | 用于语义检索 |
| Function Calling | 模型生成结构化工具调用请求 | Agent 调用工具的基础 |
| Structured Output | 按指定结构生成内容 | 便于程序可靠解析 |

学习安排：

第 17 周：认识 LLM、Transformer 基础、Token 和上下文。

第 18 周：学习模型 API、请求参数、Prompt 和流式输出。

第 19 周：学习 JSON Schema、结构化输出和 Function Calling。

第 20 周：使用 FastAPI 编写一个支持多轮对话和流式输出的 AI 聊天服务。

**阶段项目 2：AI 聊天助手**

技术栈：FastAPI + LLM API + PostgreSQL + SSE

支持流式聊天、多轮上下文、历史会话、结构化输出、模型调用失败处理和 Token 用量记录。

## 七、第 6–7 个月：RAG 知识库开发

先理解一个问题：大模型并不知道企业内部的最新业务文档，如何让它基于指定资料回答？

RAG 的基本思路是：**先检索相关资料，再将资料作为上下文交给模型生成答案。**

| 周次 | 学习内容 | 实践 |
|--------|--------|--------|
| 21 | 文档解析、文本清洗 | 解析 PDF、Word |
| 22 | Chunk 文本切分 | 比较不同切块方式 |
| 23 | Embedding、向量相似度 | 将文本转换为向量 |
| 24 | Qdrant / pgvector | 实现向量检索 |
| 25 | RAG 问答链路 | 完成知识库问答 |
| 26 | BM25、混合检索 | 对比不同检索方式 |
| 27 | Reranker、Query Rewrite | 优化召回与排序 |
| 28 | RAG 评测 | 生成检索评测报告 |

**阶段项目 3：企业知识库问答系统**

技术栈：FastAPI + Qdrant + Embedding + Reranker + LLM

支持文档上传、自动切块、索引、混合检索、引用来源和检索评测。至少建立 50–100 条人工校验的测试问题。
