# 企业知识库问答系统

第 21–28 周

让知识进入检索链路，以评测结果判断优化是否有效。

技术栈：FastAPI · Qdrant · Embedding · Reranker · LLM

## 验收要求

- [ ] 文档解析、清洗、切分
- [ ] 索引更新与元数据过滤
- [ ] 向量、BM25 与混合检索
- [ ] 答案引用与无依据拒答
- [ ] 50–100 条人工校验问题
- [ ] 有指标与错误案例的评测报告

## 开发与交付

1. 先明确数据模型与接口。
2. 实现最小可运行版本。
3. 用实际测试覆盖正常、边界和失败路径。
4. 记录部署步骤、已知限制与故障恢复方法。
5. 用自己的语言讲清设计选择和指标。

此目录为学习项目预留，业务代码需要在对应阶段逐步完成。
