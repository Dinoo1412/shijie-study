# AI 聊天助手

第 17–20 周

让模型调用变成可管理、可观测的多轮聊天体验。

技术栈：FastAPI · LLM API · PostgreSQL · SSE

## 验收要求

- [ ] 多轮上下文和历史会话
- [ ] 流式响应与客户端断开处理
- [ ] 结构化输出及字段校验
- [ ] 超时、失败与有限重试
- [ ] Token 用量和耗时记录
- [ ] 可复现演示与测试

## 开发与交付

1. 先明确数据模型与接口。
2. 实现最小可运行版本。
3. 用实际测试覆盖正常、边界和失败路径。
4. 记录部署步骤、已知限制与故障恢复方法。
5. 用自己的语言讲清设计选择和指标。

此目录为学习项目预留，业务代码需要在对应阶段逐步完成。
