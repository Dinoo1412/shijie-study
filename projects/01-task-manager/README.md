# 任务管理系统

第 9–16 周

把后端基础串起来，做一个从登录到部署都能独立运行的服务。

技术栈：Python · FastAPI · PostgreSQL · Redis · Docker

## 验收要求

- [ ] 注册与登录，密码安全存储
- [ ] 任务增删改查与分页
- [ ] 用户之间的数据隔离
- [ ] 缓存过期和一致性验证
- [ ] 关键路径和权限测试
- [ ] Docker 部署与故障排查文档

## 开发与交付

1. 先明确数据模型与接口。
2. 实现最小可运行版本。
3. 用实际测试覆盖正常、边界和失败路径。
4. 记录部署步骤、已知限制与故障恢复方法。
5. 用自己的语言讲清设计选择和指标。

此目录为学习项目预留，业务代码需要在对应阶段逐步完成。
