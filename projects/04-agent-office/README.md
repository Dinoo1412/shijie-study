## 开发与交付

1. 先明确数据模型与接口。
2. 实现最小可运行版本。
3. 用实际测试覆盖正常、边界和失败路径。
4. 记录部署步骤、已知限制与故障恢复方法。
5. 用自己的语言讲清设计选择和指标。
